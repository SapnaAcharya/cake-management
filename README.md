# Cake Management System

A full-stack cake management system built using ASP.NET Core Web API and React.js.

## Technologies

### Backend
- ASP.NET Core Web API
- Entity Framework Core
- SQL Server
- JWT Authentication
- Swagger

### Frontend
- React.js
- Vite
- JavaScript

## Features

- Customer registration and login
- JWT authentication
- Cake browsing
- Cake search and pagination
- Shopping cart
- Guest cart
- Guest checkout
- Customer checkout
- Cash on Delivery
- Order management
- Admin dashboard
- Cake management
- Category management
- User management

## Project Structure

```text
CakeManagement/

## Running the BackEnd
cd CakeManagementAPI
dotnet restore
dotnet run

## Running the Frontend
cd cake-management-frontend
npm install
npm run dev
